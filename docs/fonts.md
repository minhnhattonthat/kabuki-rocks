# Fonts

Every font or glyph sheet the build reads ends up inside the released patch, so its licence must allow that. One row
per file; a font with no known licence doesn't go into a release.

| File | Source (URL, version) | Licence | Redistributable in a patch | Used for | Changes made |
|---|---|---|---|---|---|
| `assets/font_en.txt` | drawn for this project (ASCII art, 8x16 cells) | MIT, same as repo | yes | dialogue and menu text (replaces kana tiles in the game font) | - |
| `assets/font_tiny.txt` | drawn for this project (3 px glyphs in 4x6 cells) | MIT, same as repo | yes | menu labels, item/song/shop lists, chapter-card titles | - |
| `assets/signs.txt` | drawn for this project over the original sign cloth | MIT, same as repo (the cloth around it is the original game's) | yes | town shop sign icons | - |
