Kabuki Rocks - English translation patch v{ver}
================================================

Unofficial English fan translation of Kabuki Rocks (Super Famicom, Atlus / RED, 1994).
Not affiliated with Atlus. No pre-patched ROMs: apply this patch to your own dump.

BASE ROM (No-Intro: Kabuki Rocks (Japan))
  File   Kabuki Rocks (Japan).sfc, 1572864 bytes, no copier header
  CRC32  ad324f9d
  MD5    daae6c39f7d168954e2b568c47b3bdd1
  SHA-1  391d2144290f287fb5fbc872c14a6102d98fc7f5

PATCHED ROM
  CRC32  {crc}  (2 MB; the patch expands the ROM)

HOW TO PATCH
  Apply KabukiRocks_EN_v{ver}.bps to the base ROM with Floating IPS (Flips), beat, or the online
  patcher at https://www.marcrobledo.com/RomPatcher.js/ . The patcher checks the base ROM; if it
  refuses, your dump is a different revision or has a 512-byte header.

PLAYING
  Tested in Mesen 2.1. Start the game from a cold boot (power on), not from a savestate made with
  the Japanese ROM.

KNOWN ISSUES
  - The money sign stays 両 (read "ryo").
  - Button Settings labels read "Abutton" / "Bbutton" (no room for a space).
  - In the battle item list, the weapon icon can overlap the item count.
  Report bugs (a savestate helps most): https://github.com/minhnhattonthat/kabuki-rocks/issues
